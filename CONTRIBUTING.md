# Cómo participar

1. Consulta las incidencias y la hoja de ruta antes de comenzar.
2. Describe el problema o la mejora con un ejemplo concreto.
3. Trabaja en una rama y propone un pull request con cambios pequeños y relacionados.
4. Explica las comprobaciones realizadas y cualquier limitación.
5. Actualiza la documentación que corresponda.

No adjuntes secretos ni información personal. La aceptación de contribuciones y su licencia dependen de la licencia que el propietario elija para el proyecto.
