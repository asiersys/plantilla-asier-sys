# Instalación

## Requisitos

Completa sistema operativo, versiones de runtime, hardware y espacio necesarios según el proyecto real.

## Pasos comprobados

Documenta cómo obtener el código, instalar dependencias, configurar y ejecutar. Comprueba los comandos en un entorno limpio antes de publicarlos.

## Configuración

Si necesitas variables, crea `.env.example` con nombres y valores ficticios. Nunca copies tu `.env` real. Indica qué variables son obligatorias y qué servicios externos intervienen.

## Problemas habituales

Añade errores observados, su causa y solución. No inventes requisitos de Python, Node o Docker para una aplicación que no los utiliza.
