# Elegir la licencia

Esta plantilla no impone una licencia automática a los proyectos futuros.

| Objetivo | Opción a valorar |
| --- | --- |
| Permitir uso, modificación y distribución con pocas condiciones | MIT |
| Permitir lo anterior con una concesión expresa de patentes | Apache-2.0 |
| Exigir que las versiones derivadas distribuidas mantengan las libertades | GPL-3.0 |
| Conservar derechos y no conceder una licencia abierta | Condiciones propias, revisadas según el uso |

Revisa compatibilidad con el código de terceros. Al decidir, incorpora el texto oficial correspondiente en `LICENSE` y actualiza el README. No atribuyas como propio un proyecto ajeno por haber añadido tu firma.
