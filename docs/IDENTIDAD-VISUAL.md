# Identidad visual Asier Sys

## Logotipo oficial

El archivo [asier-sys-original.png](assets/asier-sys-original.png) es la imagen original aportada por el propietario. Se utiliza directamente en la cabecera del README, sin recrear las letras, cambiar proporciones, recolorear, recortar ni añadir texto.

Puede escalarse conservando su proporción. No uses filtros CSS sobre el logotipo.

## Colores de acompañamiento

- Fondo negro: `#000000`.
- Acento ámbar orientativo: `#FFA51C`.
- Texto de lectura: `#F2F2F2`.

Estos valores sirven para acompañar la imagen; no son una medición exacta de sus píxeles. Las líneas de monitor y el brillo pertenecen al logotipo. Evita aplicarlos al texto de lectura y conserva contraste y legibilidad.
