# Ficha del proyecto

| Campo | Valor que debe completar el proyecto |
| --- | --- |
| Nombre y propósito | Pendiente |
| Usuario destinatario | Pendiente |
| Estado y versión | Pendiente |
| Windows | Indicar compatible, no compatible o no probado |
| Linux | Indicar distribuciones/versiones probadas |
| Raspberry Pi | Indicar modelo, arquitectura y sistema probado |
| Tecnología y versiones | Pendiente |
| Hardware y almacenamiento | Pendiente |
| Internet | Indicar para qué se necesita y si funciona sin conexión |
| Servicios externos | Indicar proveedor, datos enviados y finalidad |
| Costes | Indicar gratuitos, suscripción o consumo; fecha de comprobación |
| Datos almacenados | Tipo, ubicación y retención |
| Credenciales y permisos | Indicar mínimos necesarios; nunca valores reales |
| Copias y restauración | Enlazar al procedimiento de mantenimiento |
| Licencia | Pendiente de elegir |
| Soporte | Indicar canal disponible sin inventar compromisos |

“Compatible” requiere evidencia. Si una plataforma no se ha probado, escribe “no probado”.
