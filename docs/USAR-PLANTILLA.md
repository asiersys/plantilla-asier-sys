# Crear tu siguiente repositorio

## Preparación inicial en GitHub

1. Crea `plantilla-asier-sys` en la cuenta `asiersys` con la visibilidad que elijas.
2. Sube el contenido de esta carpeta; incluye `.github`, `.gitignore` y `.editorconfig`.
3. En Settings → General, activa **Template repository**.

## Para cada proyecto nuevo

1. En la plantilla, selecciona **Use this template → Create a new repository**.
2. Pon el nombre y elige visibilidad. Copia solo la rama principal salvo necesidad concreta.
3. Cambia el título, descripción, estado, plataforma y tecnología del README.
4. Completa instalación, uso, privacidad y licencia con datos reales.
5. Añade el código y una captura real. Elimina marcadores y carpetas innecesarias.
6. Configura las comprobaciones automáticas adecuadas a ese proyecto cuando existan.

Los proyectos creados desde esta plantilla son independientes: las futuras modificaciones de la plantilla no se propagan automáticamente. Las instrucciones de IA ayudan a mantener la firma, pero no la garantizan en repositorios creados por otra vía.

## Petición para un asistente

«Crea este proyecto a partir de plantilla-asier-sys. Lee AGENTS.md, conserva la autoría, adapta el README visual y la documentación a lo que realmente implementes y añade una captura real cuando funcione la interfaz.»
