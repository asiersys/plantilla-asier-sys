# Puesta en marcha de un proyecto

- [ ] Crear el repositorio con Use this template.
- [ ] Elegir visibilidad y revisar los archivos antes de publicar.
- [ ] Sustituir nombre, descripción y funciones del README.
- [ ] Completar [la ficha](FICHA-PROYECTO.md) con plataforma, requisitos, internet y costes.
- [ ] Elegir licencia y respetar atribuciones de terceros.
- [ ] Implementar el flujo principal y comprobar instalación y uso.
- [ ] Añadir una captura real sin datos personales y eliminar el marcador.
- [ ] Completar [actualización y copias](MANTENIMIENTO.md) según dónde guarda los datos.
- [ ] Revisar secretos y permisos.
- [ ] Ejecutar `python3 scripts/comprobar_documentacion.py`.
- [ ] Revisar manualmente enlaces externos, capturas y comportamiento.
- [ ] Documentar límites y actualizar CHANGELOG.
- [ ] Conservar el logotipo original y la firma según [identidad visual](IDENTIDAD-VISUAL.md).

Esta lista se completa en cada proyecto: la plantilla no representa una aplicación terminada.
