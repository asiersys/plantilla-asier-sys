# Seguridad

No publiques vulnerabilidades con secretos o datos personales en incidencias públicas.

Antes de aceptar reportes de seguridad, el propietario debe configurar un canal privado y documentarlo aquí. Si el repositorio tiene habilitada la opción «Report a vulnerability», utilízala.

No existe todavía un canal privado definido ni un compromiso de plazo de respuesta. No uses ejemplos de credenciales reales en el código o documentación.
